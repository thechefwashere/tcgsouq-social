Deprecated

The creation of new marketing activity app extensions is deprecated. Only existing extensions can still be managed. If you have an existing marketing activity app extension and would like to continue to manage it, please migrate it to CLI following the [migration guide](/docs/apps/build/marketing/marketing-activities/migrate-extensions).

**Deprecated:**

The creation of new marketing activity app extensions is deprecated. Only existing extensions can still be managed. If you have an existing marketing activity app extension and would like to continue to manage it, please migrate it to CLI following the [migration guide](/docs/apps/build/marketing/marketing-activities/migrate-extensions).

Note

If you're building a marketing automation, then you shouldn't integrate your app as a marketing activity app extension. Instead, you should use a marketing automation [Flow action extension](/docs/apps/build/marketing/automations/create-marketing-automation-actions), which can be used in [Shopify marketing automations](https://help.shopify.com/manual/promoting-marketing/create-marketing/create-marketing-automations).

# Embed a reel from Facebook onto a website

Copy link

As of September 2025, all videos posted to Facebook are shared as reels. You can [embed a Public post](/help/215768235242256?helpref=faq_content) or reel on your website.

When you embed a post that contains a reel, the message that was posted with the reel will be included. When you embed a reel directly, only the reel player will be included.

To embed a Facebook reel:

1. Open Facebook on a computer.
2. Go to the reel you want to embed.
3. Click **Options** and select **Embed**.
     
   **Note:** You will only see this option if the reel's [audience](/help/120939471321735?helpref=faq_content) is set to **Public**.
4. Copy the code that appears and paste it on your website or web page.

If you embed a reel and the audience of the reel changes from Public, a message saying the embedded reel is no longer available will appear on the website.

**Note:** Facebook doesn't currently provide the option to download reels.

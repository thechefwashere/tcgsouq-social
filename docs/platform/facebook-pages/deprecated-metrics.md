# Deprecated Facebook Page Insights Metrics



By June 15, 2025, the following Facebook Page Insights metrics were deprecated for all API versions. The API will return an invalid metric error when calling any of these metrics.

- `page_impressions_unique* (Alternative: page_total_media_view_unique)`

- `page_impressions_paid_unique*`

- `page_impressions_viral_unique*`

- `page_impressions_nonviral_unique*`

- `page_posts_impressions*`

- `page_posts_impressions_unique*`

- `page_posts_impressions_paid*`

- `page_posts_impressions_paid_unique*`

- `page_posts_impressions_organic_unique*`

- `page_posts_served_impressions_organic_unique*`

- `page_posts_impressions_viral*`

- `page_posts_impressions_viral_unique*`

- `page_posts_impressions_nonviral*`

- `page_posts_impressions_nonviral_unique*`

- `post_impressions_unique* (Alternative: post_total_media_view_unique)`

- `post_impressions_paid_unique*`

- `post_impressions_fan_unique*`

- `post_impressions_organic_unique*`

- `post_impressions_viral_unique*`

- `post_impressions_nonviral_unique*`

- `post_impressions_nonviral_unique*`
